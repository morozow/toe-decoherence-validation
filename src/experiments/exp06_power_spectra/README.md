# Experiment 06: Primordial Power Spectra

## Hypothesis

The ToE predicts modified primordial power spectra:
- P_ζ(k) = (1 + 2n̄_k) × H²/(8π²ε_H c_s) × ring-down
- P_t(k) = 2H²/π²

## Theoretical Basis

From manuscript Section 5:
- Entanglement enhances scalar spectrum by factor (1 + 2n̄_k)
- Ring-down from decoherence adds oscillatory features
- Tensor spectrum is standard

## Observables Computed

1. **P_ζ(k)** — Scalar power spectrum
2. **P_t(k)** — Tensor power spectrum
3. **n_s(k)** — Scalar spectral index
4. **r(k)** — Tensor-to-scalar ratio
