# Experiment 04: Entanglement Energy-Momentum Conservation

## Hypothesis

The entanglement fluid satisfies the conservation law:
d ln ρ_ent / dN + 3(1 + w_ent) = 0

This must hold to machine precision (~10⁻¹¹).

## Theoretical Basis

From manuscript Section 2:
- T^ent_μν is covariantly conserved
- This is a critical invariant of the theory
- Violation would indicate inconsistency

## Observables Computed

1. **Conservation residual** — Should be ~10⁻¹¹
2. **ρ_ent(N)** — Energy density evolution
3. **w_ent(N)** — Equation of state

## Key Predictions

- Residual < 10⁻¹⁰ everywhere
- Conservation holds for all parameter choices
