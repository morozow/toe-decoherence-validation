# Experiment 05: Ghost-Freedom and Stability Conditions

## Hypothesis

The ToE requires stability conditions:
- z² = 2 a² ε_H / c_s² > 0 (Mukhanov-Sasaki stability)
- α₃ ≥ 0 (ghost-freedom)
- α₂ + (1/3)α₃ ≥ 0 (positivity)

## Theoretical Basis

From manuscript Section 9.6:
- Violations imply superluminality or ghosts
- These are consistency conditions, not tunable parameters

## Observables Computed

1. **z²(N)** — Mukhanov-Sasaki variable
2. **Positivity condition** — α₂ + α₃/3
3. **Stability window** — Valid N range
